# Olist-Analyse
# Analyse 360° d'E-commerce (Olist Dataset)

## 📌 Présentation du Projet
Ce projet analyse les performances d'Olist (Brésil) sous 4 angles stratégiques : 
**Marketing, Finance, Retail, et Assurance/Risque.**

## 🛠️ Stack Technique
- **SQL (BigQuery)** : Nettoyage, jointures complexes et segmentation RFM.
- **Python (Pandas/Matplotlib)** : Analyse exploratoire (EDA) et détection d'anomalies.
- **Tableau / Looker Studio** : Visualisation des données et KPI.

## 📊 Key Insights (Ce que j'ai découvert)
- **Finance** : Identification d'un segment VIP (ex: client à 7 388 BRL) représentant une part majeure du CA.
- **Retail & Assurance** : Le retard de livraison est le premier facteur de chute de la note de satisfaction.
- **Le Paradoxe Qualité** : La catégorie `cama_mesa_banho` génère des notes de 1/5 même avec une livraison en avance (problème de conformité produit).

## 🚀 Comment utiliser ce repo
1. Les requêtes SQL sont dans le dossier `/sql`.
2. L'analyse exploratoire Python est dans `/notebooks`.
